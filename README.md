# Orum

Orum is an original programming language within the Myriad OS ecosystem. This repository is dedicated exclusively to the Orum language, including its language specification, compiler, tooling, standard library, tests, and documentation.

Orum is developed as an independent project and is intended to serve as a programming language for the broader Myriad OS ecosystem.

## Related projects

- [Myriad OS](https://github.com/Redcherryman/Myriad-OS) — the operating system at the center of the ecosystem
- [Menagerie Kernel](https://github.com/Redcherryman/Menagerie-Kernel) — the kernel, designed for future integration with Orum
